## 开源项目深度拆解
### 1. jingyaogong/minimind — 两小时从零训练你的 64M 大模型
- 解决的问题：大语言模型训练门槛高、底层原理难理解。此项目旨在以极低成本和时间，让个人开发者从零开始训练超小型语言模型，深入理解 LLM 内部机制。
- 实现要点：使用 PyTorch 原生实现所有核心算法，不依赖高层抽象库。提供完整的训练链路（Pretrain, SFT, LoRA, RLHF, Agentic RL等），主线结构对齐 Qwen3/Qwen3-MoE，包含 tokenizer 和高质量数据集。模型体积极小，方便个人复现和实验。
- 适用人群与局限：LLM 初学者、资源有限的个人开发者、学生，用于学习和轻量级实验。局限是 64M 模型通用能力有限，主要用于教学而非生产。项目内“2小时3块钱”指SFT阶段单卡3090的耗时与租用成本。
- 项目地址：https://github.com/jingyaogong/minimind

### 2. EL4CTEO/fast-anything — 别重写整个应用，只用 Rust 优化那 5% 的慢代码
- 解决的问题：整个应用用 Rust 重写成本高昂，而大部分性能瓶颈集中在少数几个热点函数。此工具旨在精准识别并用 Rust 优化这些热点函数，实现局部性能飞跃。
- 实现要点：通过 `scan` 命令进行性能分析，识别热点函数。`port` 命令记录真实调用数据。利用 AI 编码 Agent 将函数重写为 Rust。`verify` 命令严格验证 Rust 实现与原版行为一致性。`enable/disable` 命令无缝切换。支持 Python, Node, Ruby, Java, Go, C# 等多语言。
- 适用人群与局限：需要性能优化的多语言栈开发者，特别是使用 AI 编码助手的团队。局限是仍需 Rust 基础来审查代码，主要针对计算密集型函数，对 I/O 密集型不适用。
- 项目地址：https://github.com/EL4CTEO/fast-anything

### 3. wangzan101/Mika — 手机上的 AI Agent，自动操作应用和网页
- 解决的问题：手机上重复性的跨应用操作耗时费力，传统自动化工具依赖 API 且配置复杂。Mika 旨在像人一样理解屏幕，自动完成任何手机任务。
- 实现要点：在隐藏后台屏幕运行，通过视觉理解和 UI 元素识别，模拟用户点击、输入和滚动，无需应用 API。数据本地处理，支持连接用户自己的 LLM API Key。能记住偏好，将任务转化为技能。
- 适用人群与局限：安卓用户，希望自动化手机日常操作；对移动 AI Agent 技术感兴趣的开发者。局限是仅支持安卓，首次设置需无线调试，智能程度依赖外部 LLM，可能占用系统资源。
- 项目地址：https://github.com/wangzan101/Mika
